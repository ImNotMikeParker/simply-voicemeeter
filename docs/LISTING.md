**Name:** Simply Voicemeeter

**Version:** 1.0.0

**Category:** Audio

**Summary:** Voicemeeter on your Stream Deck, live: mute keys with meters, gain keys and dials, one-tap output device
swapping, routing, macro buttons, presets and scripts.

**Description:**

Simply Voicemeeter puts Voicemeeter, Banana or Potato on your Stream Deck through VB-Audio's official Remote API, so
every key follows what Voicemeeter is actually doing, including changes you make in Voicemeeter itself.

- Mute: toggle, push-to-talk or set, with the live state and a level meter on the key.
- Gain: press for one value, hold for another, with an optional fade. Live dB and meter.
- Output Device: send a bus to a device, or swap a bus between two (headset / speakers) with the live one highlighted.
  Add your own label and image per device.
- Route: toggle a strip's A1 / A2 / A3 / B1 / B2 assignment.
- Macro Button: toggle or push, state shown live.
- Script: Voicemeeter's own command syntax (Strip[0].Mute=1; Bus[0].Gain=-6;) with press / hold, toggle, or
  push-to-talk modes and optional live state from any parameter.
- Preset: recall a scene or load a saved configuration.
- Stream Deck +: a Gain dial with the label, dB, a gain bar in the color you choose with a "hot" segment above 0 dB,
  and a live level meter. Rotate for gain, press for solo, tap for mute.

Every dropdown is filled from Voicemeeter: strips and buses by the labels you gave them, output devices from
Voicemeeter's device list. No indexes to remember. Polling is light: Voicemeeter's change flag every 100 ms, meters only
while one is on screen.

Requires Voicemeeter (any edition) installed and running on Windows. Not affiliated with VB-Audio Software. Free and
open source (MIT).
